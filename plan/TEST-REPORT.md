## 2. 缺陷清单

### BUG-01（S3）播放中断网：缓冲耗尽后画面永久冻结，无任何提示，网络恢复不自愈

- **用例**：STAB-002（播放中断网 → 应报错可重试）
- **复现步骤**：游客态播放任意视频 → 确认正在播放（帧差>1.1亿）→ 开启飞行模式 → 缓冲耗尽后（约 1-5 分钟，或 seek 到未缓冲区加速）观察
- **实际结果**：画面停帧（连续 8 秒帧差=0）、无错误覆盖层、无加载指示、无重试入口；关闭飞行模式网络恢复后 10 秒仍不自愈，必须退出播放页重进
- **证据**：`STAB-002a-offline.png`（离线冻结帧）；网络恢复后帧差=0
- **根因分析**（代码走查）：`PlayerActivity` 未处理长时间 `STATE_BUFFERING`；OkHttp 数据源在路由被撤后未触发 `onPlayerError`，加载层 `loadingOverlay` 在 `prepare()` 后已隐藏，ExoPlayer 默认无 stall 超时兜底
- **影响**：孩子看片途中网络抖动 → 黑屏卡死无反馈
- **建议**：监听 BUFFERING 状态超过 N 秒展示错误层/重试；或为数据源设置更激进的读超时并验证断链触发路径

### BUG-02（S3）仅有中文字幕轨（无英文轨）的视频，中文字幕完全不显示

- **用例**：SUB-004（仅中文轨 → 中文行显示、不启 Vosk）
- **复现步骤**：登录态播放 d001（小猪佩奇 Muddy Puddles，P1 仅有 `ai-zh` 轨——主机接口核实该轨 5.2s 起即有台词"泥泞的水坑"）→ 观察字幕区
- **实际结果**：60 秒内多帧采样（含 2.2 倍放大 OCR）字幕区无任何文字；英文行空 → 中文行也不画
- **证据**：cc1-cc10 采样帧全空；主机侧 `x/player/v2` 证实轨存在且内容正常；对照 d004（仅 ai-en）英文行正常显示（"Daddy? I can't find George anywhere"）→ 渲染链路本身正常
- **根因分析**（代码定位）：`BiSubtitleView.onDraw()` 第一行 `val eOutline = enOutlineLayout ?: return`——英文行为空时**提前 return，中文行永远不绘制**
- **影响面**：大。登录后 ai-zh 中文轨近乎全量、ai-en 英文轨仅部分视频有 → 大量"单中文轨"片源全程无字幕，且因"有轨不跑识别"规则 Vosk 也不会兜底
- **建议**：`onDraw` 改为英文行可空时仍绘制中文行（zh 位置相应上移）

### OBS-01（S4）触摸模式下卡片/搜索条需双击才激活

- `focusableInTouchMode` 视图（卡片、搜索条）首次点按仅获焦点，第二次才触发点击；遥控器/键盘不受影响，手机侧载触屏体验受影响。实测双击可正常进详情/搜索。
- 建议：TV 优先可接受；如需触屏友好，卡片视图去掉 touch-mode 焦点抢占

### OBS-02（S4）扫码页已生成二维码后断网无状态提示

- 二维码生成成功后再断网，轮询静默失败（状态停留在"等待扫码…"）；仅"生成阶段"断网才显示"网络错误，正在重试…"（该路径已验证 ✅，网络恢复自动出码）。建议轮询连续失败 N 次也提示网络状态。

### OBS-03（部署提醒）调试用高版本配置会污染版本仲裁

- 测试中设备缓存过 v200 配置后，真实 v3 片单因 `version < cached` 被拒绝（版本回退保护**按设计工作**，两次验证 ✅）。**部署者注意**：用过测试配置的设备需 `pm clear` 才能回到低版本正式片单。

### BUG-01 修复（PlayerActivity 卡顿看护）

- **改动**：250ms tick 内新增看护——`playWhenReady 且进度 30s 无任何前进` 判定断流；DASH 先自动降级 MP4（会话级 dashBlocked），非 DASH/已降级则展示错误层「画面卡住了，可能是网络中断；请检查网络后重试」+ 重试按钮；顺带将"获取分P失败"文案补充"或网络中断"、MP4 地址失败文案按登录态区分
